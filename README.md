# Hi, I'm Erfan 👋

I'm passionate about **programming** and **embedded systems**, from designing circuits and PCBs to building mechanical parts and writing firmware.

## 🚀 Current Project: M.E.O (Mini Embeded OS)

M.E.O is a compact, Flipper Zero-inspired handheld system built around the **ESP32-S3**. It features a full-color display and a smooth, detailed user interface, all running on a custom lightweight embedded OS.

**Highlights**
- ESP32-S3 microcontroller
- Color display with a fluid, polished UI
- Custom PCB designed in Altium Designer
- Enclosure designed in SolidWorks
